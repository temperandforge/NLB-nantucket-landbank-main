# Design docs from nlb-design

These are the docs of the standalone `nlb-design` project (Figma-to-code conventions, typography,
token notes, component notes), moved into this repo on 2026-10-07 when its components were
absorbed as Sanity-driven blocks. See
[the absorption spec](../superpowers/specs/2026-10-07-absorb-nlb-design-design.md).

They are kept as written, so some paths and examples refer to `nlb-design`'s layout (for example
`css/components/`) rather than this repo's. Where they conflict with [`../DECISIONS.md`](../DECISIONS.md),
`DECISIONS.md` wins.
